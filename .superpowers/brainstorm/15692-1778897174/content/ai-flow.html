How should the AI generation work?

The user described it as: "describe the issue → model generates a nice description." There are three honest interpretations. Pick one — the rest of the dialog design follows from this.

A. Polish-in-place recommended

One textarea. User types whatever — rough notes, bullets, stream-of-consciousness. Clicks "✨ Polish with AI" → text is rewritten in the same field. User can edit the result, polish again, or undo.

– No "before/after" preview · destructive (must trust the rewrite)

B. Two-pane (rough → polished) side-by-side

Left pane: rough notes (always editable). Right pane: AI-generated markdown (regenerates on demand). User can edit either; the right pane is what gets submitted.
