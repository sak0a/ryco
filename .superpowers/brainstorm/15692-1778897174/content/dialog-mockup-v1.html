Open assumptions baked into this mock:

  • Repo is inferred from the current project's primary remote — no picker.
  • AI buttons ("Suggest from body", "Polish with AI", "↻ Regenerate" branch) all call the same textGeneration service with the global model. No model picker in the dialog.
  • Title suggest is manual — clicking it rewrites the title. The polish button does the body only.
  • Labels/assignees pre-fetched from the provider (cached); add-chip opens a searchable popover. Optional in v1.
  • Worktree checkbox defaults to ON (matches your "directly create worktree from this"). Branch name auto-fills after body has content; user can click ↻ to regenerate or edit inline.
  • After submit: dialog closes, issue list refreshes, new issue is selected; if worktree was created, it opens in the sidebar.
